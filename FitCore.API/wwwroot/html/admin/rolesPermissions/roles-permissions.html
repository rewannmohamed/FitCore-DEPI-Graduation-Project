Roles & Permissions

What each staff role can see and do across the FitCore ecosystem.

Permissions are fixed per role and defined in code — there's no separate permissions table to keep in sync, and no "custom role" to accidentally misconfigure. To change what a role can do, a developer updates the role's checks directly. The toggles below are read-only, for reference.
